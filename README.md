> [!NOTE]
> **FACED** — sFace Recognition & Identity Intelligence Platform.


A high-performance, standalone biometric face recognition and identity intelligence platform. Features deep neural network face detection, 128D facial feature embedding extraction, Facebook Research FAISS vector indexing, native multi-threaded Rust SIMD acceleration, document OCR parsing, and tactical cyberpunk-grade analytics.


> [!IMPORTANT]
> ## 🔒 Data Privacy & Security Notice
>
> FACED was tested internally on real-world data. For privacy and data security reasons, **that real database is not included in this repository, will not be shared, and will not be provided on request.** Any request for it or for personal information from it will be ignored.
>
> ### 🧪 Dummy Data in This Repo
> The database and vectors in `data/` are **synthetic test data only**, generated with `seed_dummy_database.py`. The names, faces, IDs, and other details do not belong to real people.
>
> ### 🗄️ Create Your Own Database
> - **Reset to demo data:** run `python3 seed_dummy_database.py` to regenerate the synthetic database.
> - **Your own data:** enroll faces through the web UI (**Save to Face Database**) or the `POST /api/face/database/add` endpoint. Only use faces you are legally authorized to process.
> - **Local only:** everything runs on your machine, and the SQLite database (`face_database.db`) and FAISS index (`face_vectors.faiss`) stay in the `data/` folder. Nothing is uploaded to external servers.
>
> ### ⚖️ Responsible Use
> Use this tool only with lawful authorization and consent, and follow your local privacy and biometric data laws (GDPR, CCPA, BIPA, etc.). The author is not responsible for misuse.

## 🛠️ Installation & Setup

### Prerequisites
* **Linux (x86_64 or aarch64)**
* **Python 3.10+** (Python 3.14 compatible)
* **Rust & Cargo** (for compiling native acceleration library)

### 1. Automatic One-Step Setup
Run the included setup script to compile the Rust library, verify Python dependencies, and check neural models:
```bash
cd /home/h9871/faced
chmod +x setup.sh run.sh rust_engine/build.sh
./setup.sh
```

## 🚀 Running the Platform

To start the standalone web server:
```bash
cd /home/h9871/faced
./run.sh
```
Or directly with Python on a custom port:
```bash
PORT=8005 python3 app.py
```

Once started, navigate in your web browser to:
👉 **`http://127.0.0.1:8005`**
