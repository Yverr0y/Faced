
# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, inclusive, and harassment-free environment for everyone participating in the Faced project and its community.

We value collaboration, technical excellence, responsible development, and constructive communication, regardless of experience level, background, identity, or technical expertise.

## Our Standards

Examples of behavior that contribute to a positive environment include:

- Being respectful, professional, and considerate.
- Welcoming constructive feedback and different technical perspectives.
- Providing clear, helpful, and respectful feedback.
- Taking responsibility for mistakes and learning from them.
- Respecting the privacy, security, and contributions of others.
- Maintaining professional communication in issues, pull requests, discussions, and community spaces.

Unacceptable behavior includes:

- Harassment, discrimination, intimidation, or personal attacks.
- Publishing private information without explicit permission.
- Sharing malicious code, unauthorized credentials, or harmful payloads.
- Deliberately disrupting project development or community discussions.
- Submitting deceptive, misleading, or intentionally harmful contributions.
- Using Faced or its components to facilitate unauthorized biometric surveillance, identity abuse, stalking, or privacy violations.

## Responsible Use of Biometric Technology

Faced incorporates facial detection, biometric feature extraction, similarity matching, and identity-related data processing.

Contributors and users are expected to:

- Process biometric information only when legally authorized.
- Obtain appropriate consent before collecting or enrolling personal biometric information.
- Respect applicable privacy and data protection regulations.
- Never distribute private biometric databases or personal information without authorization.
- Avoid presenting facial similarity scores as definitive proof of identity.
- Handle biometric records, embeddings, and associated metadata securely.
- Report suspected privacy violations or security vulnerabilities responsibly.

The project is intended for lawful, authorized, and responsible applications. Contributors must not introduce features specifically designed to facilitate unlawful surveillance, harassment, or unauthorized identification.

## Contribution Guidelines

All contributors are expected to:

1. Follow the project's contribution guidelines.
2. Write clear and maintainable code.
3. Document significant changes and new functionality.
4. Avoid committing credentials, private datasets, or sensitive personal information.
5. Respect the project's licensing terms.
6. Provide sufficient context when submitting issues or pull requests.
7. Cooperate respectfully during code reviews.

Contributions may be reviewed, modified, or rejected if they violate project policies, licensing requirements, or responsible-use principles.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Maintainers may take appropriate action in response to unacceptable behavior, including:

- Removing inappropriate comments or contributions.
- Issuing warnings.
- Temporarily restricting participation.
- Closing issues or pull requests.
- Permanently banning individuals from project spaces in serious or repeated cases.

Enforcement decisions will be made based on the severity and circumstances of each incident.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub repositories and discussions.
- Issues and pull requests.
- Community communication channels.
- Project-related events and collaborations.
- Any other space where an individual represents the Faced project.
